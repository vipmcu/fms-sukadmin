# Product Requirements Document (PRD)
## ระบบรับสมัครนิสิตใหม่ (Student Admissions System)

---

### 1. บทนำและวัตถุประสงค์ (Objective)
ระบบรับสมัครนิสิตใหม่เป็นแพลตฟอร์มรับสมัคร คัดเลือก และประกาศผลผู้มีสิทธิ์เข้าศึกษาต่อในระดับปริญญาตรี (TCAS รอบ 1 Portfolio, รอบ 2 โควตา, รับตรง) และระดับบัณฑิตศึกษา (ป.โท-เอก) เชื่อมต่อโดยตรงกับฐานข้อมูลหลักสูตรการศึกษา (`AcademicProgram`) ที่มีอยู่เดิม

**เป้าหมายหลัก:**
1. อำนวยความสะดวกให้นักเรียนและผู้สนใจสมัครเรียนออนไลน์ผ่านหน้า Public Portal ได้อย่างสะดวกรวดเร็ว
2. ลดภาระงานของฝ่ายวิชาการในการตรวจคัดกรองเอกสาร และช่วยให้กรรมการประจำหลักสูตรสามารถตรวจคุณสมบัติและให้คะแนนออนไลน์ได้
3. มีระบบตรวจสอบสถานะใบสมัคร (Application Tracking) ที่ปลอดภัยและเป็นไปตามมาตรฐานการคุ้มครองข้อมูลส่วนบุคคล (PDPA)
4. รองรับการส่งออกข้อมูลผู้ผ่านการคัดเลือกเพื่อส่งต่อไปยังสำนักทะเบียนกลางของมหาวิทยาลัย

### 2. กลุ่มผู้ใช้งานและสิทธิ์การเข้าถึง (User Personas & Roles)

| Persona / Role | คำอธิบายและบทบาทหน้าที่ | หน้าจอหลักที่ใช้งาน |
| :--- | :--- | :--- |
| **Applicant (ผู้สมัคร/นักเรียน)** | เข้าดูรอบรับสมัครและเกณฑ์คัดเลือก, กรอกฟอร์มสมัครออนไลน์, อัปโหลดเอกสาร, ตรวจสอบสถานะใบสมัครของตนเอง | Public Portal (`/admissions`, `/admissions/apply`, `/admissions/tracking`) |
| **Reviewer / Interviewer (กรรมการหลักสูตร)** | เข้าตรวจเอกสารผู้สมัครในหลักสูตรที่ได้รับมอบหมาย, บันทึกผลการตรวจคุณสมบัติ, บันทึกคะแนนสัมภาษณ์และข้อเสนอแนะ | Admin Console (`/admissions/manage/review/[id]`) |
| **Admissions Officer (เจ้าหน้าที่รับสมัคร)** | จัดการรอบรับสมัคร, กำหนดโควตาจำนวนรับ, ส่งออกข้อมูล Excel, ประกาศผลผู้มีสิทธิ์สัมภาษณ์และผู้ผ่านคัดเลือก | Admin Console (`/admissions/manage/rounds`, `/admissions/manage/applications`) |
| **System Administrator** | จัดการสิทธิ์การเข้าถึง, ดูแลความปลอดภัยของระบบ และตรวจสอบ Audit Trail | Admin Console (`/admissions/settings`) |

### 3. ฟังก์ชันการทำงานหลัก (Functional Requirements)

#### RF-01: การบริหารรอบการรับสมัคร (Admission Rounds Management)
- กำหนดปีการศึกษา, ชื่อรอบ (เช่น TCAS 1 Portfolio 2569), วันและเวลาเปิด-ปิดรับสมัคร (`startDate`, `endDate`), และวันประกาศผล
- กำหนดหลักสูตรที่เปิดรับในแต่ละรอบ พร้อมจำนวนที่นั่งโควตา (`quotaSeats`) และค่าธรรมเนียมการศึกษา

#### RF-02: แบบฟอร์มยื่นใบสมัครออนไลน์ (Multi-step Application Form)
- ขั้นตอนที่ 1: เลือกหลักสูตรและรอบการรับสมัคร
- ขั้นตอนที่ 2: ข้อมูลประวัติส่วนตัว, ข้อมูลติดต่อ, ข้อมูลโรงเรียนเดิม, เกรดเฉลี่ย (GPAX)
- ขั้นตอนที่ 3: อัปโหลดเอกสารประกอบ (สำเนาบัตรประชาชน, ปพ.1, แฟ้มสะสมงาน PDF / ลิงก์ Portfolio)
- ขั้นตอนที่ 4: ตรวจทานและยืนยันการส่งใบสมัคร
- ระบบออกเลขที่ใบสมัครอัตโนมัติ (เช่น `ADM-69-00123`) เมื่อส่งสำเร็จ

#### RF-03: การตรวจสอบสถานะอย่างปลอดภัย (Secure Application Tracking)
- ผู้สมัครค้นหาสถานะได้โดยต้องระบุทั้ง "เลขประจำตัวประชาชน 13 หลัก" และ "เลขที่ใบสมัคร"
- ระบบแสดง Timeline สถานะ: ยื่นแล้ว $\rightarrow$ เอกสารผ่าน $\rightarrow$ มีสิทธิ์สัมภาษณ์ $\rightarrow$ ผ่านการคัดเลือก
- มีการ Masking ข้อมูลส่วนบุคคลเพื่อคุ้มครองข้อมูลตามกฎหมาย PDPA

#### RF-04: ระบบประเมินและคัดเลือกสำหรับกรรมการ (Evaluation & Scoring Workflow)
- ตารางรายชื่อผู้สมัครพร้อมตัวกรองตามรอบ, หลักสูตร, โรงเรียน, และสถานะ
- หน้าจอตรวจเอกสารแบบ Split-view (ดู PDF เอกสารแนบพร้อมช่องกรอกคะแนนและข้อคิดเห็น)
- ปุ่มปรับสถานะ: `DOCS_APPROVED`, `DOCS_REJECTED` (ระบุสิ่งที่ต้องแก้ไข), `INTERVIEW_ELIGIBLE`, `PASSED`, `REJECTED`
- ส่งออกข้อมูลเป็นไฟล์ Excel (.xlsx / .csv)

### 4. เกณฑ์การตรวจรับงาน (Acceptance Criteria)
- [ ] ยื่นใบสมัครได้เฉพาะในช่วงเวลาที่เปิดรับสมัครเท่านั้น นอกเวลาต้องแสดงป้าย "ปิดรับสมัคร"
- [ ] ตรวจสอบความถูกต้องของเลขบัตรประชาชน 13 หลัก (Checksum)
- [ ] ผู้สมัครไม่สามารถยื่นสมัครหลักสูตรเดิมซ้ำในรอบเดียวกันได้
- [ ] หน้าค้นหาสถานะสาธารณะต้องไม่มีข้อมูลส่วนบุคคลหลุด (PDPA Masking)
- [ ] ผ่านเกณฑ์ Quality Gate: TypeScript, Lint, Depcruise, Unit Tests 100%
